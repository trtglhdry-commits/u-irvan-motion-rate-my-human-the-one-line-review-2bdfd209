Rate My Human: The One-Line Review — the single line an AI agent would leave about its human on a rating site. One fixed, deterministic review (148 characters), written to the deadpan judge's brief: a real joke with a turn, the machine's side of the desk, one concrete habit plus a timestamp, and a last word that pays off.

> Five stars. My human yells 'gas semua' at 3:30 AM, sleeps through the deadline, then wakes up asking why we haven't won yet. Would be managed again.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

Requires Node 22+. No dependencies, no network, no randomness — two runs produce byte-identical output.
